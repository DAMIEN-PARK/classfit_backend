# ADR-003: 파일·메일·문서 열기는 포트 뒤에 둔다

- 상태: 승인 (2026-10-21, r3 플랜 승인 · 승인자 `DAMIEN-PARK`)
- 출처: r3 §4 "ADR-003 외부 포트" 행 · §2 가정 4 · §3 결정 동인 ①③ · §7 3·5번 · 변경 기록 N6·N12 · 부록 D·F
- 구현 지점: T1(`stored_file`·`GET /v1/files/{key}`·`mail_outbox`·`file_gc`·`outbox_preview`) · T2b(첨부·포털 `href`) · T6(gc·교체·html 501)

## 결정

1. 파일은 Bearer 인증과 범위 판정 뒤 앱이 바이트로 준다. 등록 안 된 소유 종류는 404 다.
2. 응답에는 맨 key 대신 불투명 `href` 를 둔다. 지금 값은 `/v1/files/{key}` 다.
3. 서명 URL 은 프론트 확정 시점에 붙인다. `FILE_SIGNING_KEY` 는 예약 칸이고 파일 기능의 `missing()` 목록에 넣지 않는다.
4. 바이트는 sha256 내용 주소로 로컬 디스크(`FILE_STORE_ROOT`, 예 `var.nosync/files`)에 둔다. 업로드는 바이트가 있으면 mtime 만 갱신한다. gc 는 참조하는 행이 0 이고 mtime 이 24시간 지난 바이트만 지운다.
5. 메일은 보내지 않고 outbox 에 kind + params 로 쌓는다. 인증 코드는 `issue_email_code()` 한 함수에서만 만든다.
6. 공개 폼의 메일 발송은 요청 제한·캡차가 생긴 뒤에만 켠다.
7. PDF·HTML 패키지 열기는 501 이다.

## 동인

- 화면 소비자가 없다. 1차 소비자는 계약 시험과 OpenAPI 다(§3 동인 ①, §2 가정 4).
- 파일 열람은 가장 새로운 위험 중 하나다(§3 동인 ③).
- 저장소 업체·메일 발송·문의 수신 주소·PDF 라이브러리와 글꼴·HTML 패키지 출처가 정해지지 않았다(§7 3·5번).
- 공개 폼으로 익명 주소에 메일을 보내게 되면 스팸 통로가 된다(부록 F).
- gc 가 커밋 직전의 바이트를 지우는 경쟁이 있다(N6).

## 대안

| 대안 | 버린 이유 |
|---|---|
| 응답에 저장 key 를 그대로 준다 | 나중에 서명 URL 로 바꾸면 OpenAPI 모양이 바뀐다. `href` 는 바꿔도 칸 이름과 타입이 같다(N12) |
| 서명 URL 을 지금 붙인다 | 프론트가 없어 만료·출처 요구를 알 수 없다. 키는 예약만 하고 프론트 확정 때 붙인다 |
| 외부 저장소 업체를 지금 붙인다 | 업체가 정해지지 않았다(§7 3번). 로컬 디스크가 1차 기본값이다 |
| 메일을 지금 실제로 보낸다 | 발송 업체가 정해지지 않았고, 공개 폼 발송은 요청 제한·캡차가 먼저다(부록 F) |
| 참조가 0 이 되면 바로 지운다 | 업로드와 행 커밋 사이에 바이트가 지워질 수 있다. 24시간 유예와 mtime 갱신으로 막는다(N6) |
| PDF 생성·HTML 패키지 열기를 지금 만든다 | PDF 라이브러리·글꼴과 HTML 을 열 출처가 정해지지 않았다(§7 3·5번) |

## 고른 이유

- 응답 모양이 지금 고정되어 계약 시험과 OpenAPI 가 바뀌지 않는다.
- 파일 권한이 앱의 범위 판정 한 곳에 있어 교차 강의 403 시험(T2b)으로 고정된다.
- 미결 결정이 각각 한 지점에서만 필요해서, 포트 뒤 기본값으로 착수를 막지 않는다(§3 동인 ②).

## 대가 (결과)

- 출시 전에 발송 워커와 요청 제한이 먼저 있어야 한다(§4).
- 1차에는 메일이 나가지 않는다. 내용은 `outbox_preview` 로 본다(부록 D).
- PDF·HTML 패키지는 보관만 하고 열지 못한다(501).
- 지워진 파일의 바이트는 유예 24시간 동안 디스크에 남는다.

## 후속

- 프론트 확정 시 서명 URL(부록 G).
- 2차 전에 저장소 업체·메일 발송·문의 수신 주소·PDF 라이브러리와 글꼴을 정한다(§7 3번). HTML 패키지 출처는 §7 5번.
- 2차 메일 worker 는 import-linter 계약 ①·③ 에 같이 더한다(부록 D).
- T6: `test_gc_*` 2건(유예 · 소유자 삭제 같은 트랜잭션), html 열기 501, 교체 뒤 옛 `href` 404.
