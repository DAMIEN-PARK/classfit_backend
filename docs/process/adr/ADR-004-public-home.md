# ADR-004: 공개홈은 화면을 보류하고 API 만 만든다

- 상태: 승인 (2026-10-21, r3 플랜 승인 · 승인자 `DAMIEN-PARK`). r3 §7 1번 질문의 답에 따라 다시 본다.
- 출처: r3 §4 "ADR-001 시안 · ADR-004 공개홈" 행 · 부록 A5 · §2 가정 2 · §7 1번 · 부록 G 후속 · r1 §2 가정 2
- 구현 지점: T2b(P3 입장) · T3(P4 강사 로그인·가입) · T4(P2 카탈로그 질의 함수) · T9a(P5 자가진단 토큰) · T9b(P6 교육 문의 접수)
- 검토 기록: [시안 검토](../research/2026-10-21-mockup-review.md) A5

## 결정

1. 공개홈은 별도 트랙이다. 루트의 `공개홈_v24.html` 은 커밋하지도 고치지도 않는다(r3 §2 가정 2).
2. 공개홈 화면은 1차에 만들지 않는다.
3. 공개홈 화면이 기대는 API 는 만든다. P3 입장은 T2b, P4 강사 로그인·가입은 T3, P5 자가진단 응답은 T9a, P6 교육 문의 접수는 T9b 다.
4. P2 카탈로그는 질의 함수 `published_catalog()` 와 통합 시험까지만 만든다. 공개 끝점은 §7-1 답 뒤에 연다.
5. 입장 실패 이유는 problem type 으로 구분한다. 화면이 생겨도 판정은 서버에 있다(검토 A5 P3 행).
6. 교육 문의의 메일 발송은 요청 제한 뒤에만 켠다. 1차는 outbox 에 쌓기만 한다([ADR-003](ADR-003-external-ports.md)).

## 동인

- 공개홈 파일이 `시안/` 에서 저장소 루트로 옮겨졌고, 이유는 모른다(r3 §2 가정 2, §7-1).
- 세 채널의 흐름이 공개홈 화면을 입구로 쓴다. 수강생 입장·강사 가입·자가진단·교육 문의가 그 화면에서 시작한다(검토 A5).
- 카탈로그 끝점·CORS 출처·봇 방지 수준은 공개홈을 어디에 둘지(§7-1)에 달려 있다.
- 공개 폼으로 익명 주소에 메일을 보내면 스팸 통로가 된다(r3 부록 F).

## 대안

| 대안 | 버린 이유 |
|---|---|
| 공개홈 화면도 1차에 만든다 | 트랙이 정해지지 않았다(§7-1). 화면 소비자와 배치가 정해지기 전에 만들면 버릴 수 있다 |
| 공개홈에 기대는 API 까지 전부 미룬다 | 입장·가입·자가진단·문의의 입구가 끊겨 흐름을 끝까지 시험할 수 없다(검토 A5 "막히는 것") |
| 카탈로그 공개 끝점도 지금 연다 | CORS 출처와 봇 방지 수준이 §7-1 답에 달려 있다. 질의 함수와 통합 시험으로 규칙(공개 ∧ 활성, 강사 이름 없음)은 지금 고정한다 |

## 고른 이유

- 입구 API 가 있으면 화면 없이도 세 채널의 흐름이 계약 시험으로 끝까지 돈다.
- 카탈로그의 공개 규칙은 질의 함수 시험으로 고정되므로, 나중에 끝점을 열어도 규칙이 바뀌지 않는다.
- 공개홈 파일을 건드리지 않아 사용자의 결정(§7-1)을 앞지르지 않는다.

## 대가 (결과)

- 1차에는 공개 카탈로그 끝점이 없다.
- 입장·강사 가입·진단 토큰·문의의 공개 API 가 화면 없이 먼저 열린다(r1 I 결과).
- 교육 문의 확인 메일이 나가지 않는다. 담당자는 outbox 로만 본다.
- 공개홈의 로그아웃·진단 링크(강사.html:867 · 관리자.html:1156)가 가리키는 화면이 1차에는 없다(검토 A5).

## 후속

- r3 §7-1 의 답을 받으면 이 ADR 과 카탈로그 끝점을 다시 본다(r3 부록 G).
- 2차: 요청 제한·캡차 뒤 공개 폼 발송, 관리자 문의 목록. T9b: 접수 끝점 `POST /v1/inquiries`(honeypot · 1분 재제출 · 본문 64KiB · JSON 이 아닌 Content-Type 415 · 이메일당 하루 20건 · outbox 2행) + 관리 명령 `inquiry_gc`. 공개홈 폼에 honeypot 칸 `website` 를 더할 때 화면의 숨은 입력은 `autocomplete="off"` · `tabindex="-1"` · `aria-hidden="true"` 로 둔다(브라우저·비밀번호 관리자의 자동 채움이 정상 문의를 honeypot 으로 버리지 않게 — T9b 리뷰 Nit 3). 관리자 문의 목록·주소 기준 요청 제한·캡차는 그대로 2차 — 그 전에는 끝점을 공개 인터넷에 노출하지 않는다.
- T4: `published_catalog()` 의 공개 ∧ 활성·강사 이름 없음 시험(Design 부록 A `test_no_personal_keys_catalog`).
