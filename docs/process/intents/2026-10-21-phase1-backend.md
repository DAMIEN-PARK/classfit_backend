# Intent: 1차 백엔드 — 화면 없이 API·DB·계약 시험으로

- 종류: feature
- 원 작성자: DAMIEN-PARK · 초안: Claude · 상태: approved
- 승인: DAMIEN-PARK 2026-10-22 (가지 T0b-sdlc-okf 의 승인 빈 커밋 `approve: T0b` c19aadd·e9998db. 범위 결정의 출처인 r3 플랜은 2026-10-21 에 승인됐다)
- 대체: 없음
- 상위 intent: [intent.md](../intent.md)

## 문제

1. 화면 소비자가 없다. 프론트 구현 주체가 정해지지 않았고, 1차 소비자는 계약 시험과 `/v1/openapi.json` 뿐이다(r3 §3 결정 동인 ①, §2 가정 4).
2. 시안 3종은 판정을 화면 상수·수동 토글·화면 계산으로 한다. 서버가 판정해야 할 규칙이 13가지다([시안 검토](../research/2026-10-21-mockup-review.md) A4).
3. 시안과 기획안의 데이터 계약이 11곳에서 다르다(검토 A2).
4. 시안에만 있고 기획안 v3 에 없는 기능이 5종이다(검토 A3).
5. 공개홈이 별도 트랙으로 빠지면서 수강생 입장·강사 가입·자가진단·교육 문의의 입구 화면이 끊긴다(검토 A5).
6. 가장 새로운 위험은 비밀번호 없는 수강생과 파일 열람이다(r3 §3 동인 ③).

## 바라는 결과

r3 §6 의 수용 기준이다. 개수 기준은 1차 마지막 병합(T9b) 기준이고, 태스크마다는 그 T 가 더한 시험만 잰다.

1. `alembic heads` 출력이 정확히 `0011 (head)` 한 줄이다(E-8). 마이그레이션 0002~0011 이 한 줄기다.
2. 입장 계약 시험이 규약 이름으로 정확히 13개 있고 전부 통과한다. P3 7행 9건 · 재발급 2 · 교차 강의 403 · 이름 비덮어쓰기다(E-10).
3. 정원·재발급(2)·로그인 잠금·열린 설문 동시성 시험 5개가 통과한다(E-11).
4. 시안 값 대조 시험(`test_golden_*`)이 2개 이상 있고 통과한다(E-12).
5. OpenAPI 경로 집합이 `tests/contracts/expected_paths.txt` 와 같고, 시험 전용 `/v1/_probe` 는 없다(E-13).
6. 개인 키 없음 시험 4곳(포털·카탈로그·I7·A5)과 gc 시험 2개가 통과한다(E-14).
7. 규칙과 시험 이름의 대응은 [Design 부록 A](../2026-10-21-phase1-backend-design.md) 표에 있다. 병합된 T 의 행마다 시험이 있는지 `scripts/check_docs.sh` 가 잰다(E-9).

## 1차에 하는 것

- 관리자·강사·수강생·진단 응답자의 API 와 DB 를 위험 순서 관통 슬라이스로 만든다. 태스크는 T1·T2a·T2b·T3~T8·T9a·T9b 이다([plan.md](../plan.md) 3절).
- 공개홈 화면이 기대는 API 는 만든다. P3 입장은 T2b, P4 강사 가입·로그인은 T3, P5 자가진단 응답은 T9a, P6 교육 문의 접수는 T9b 다. P2 카탈로그는 T4 의 질의 함수까지만 만든다(검토 A5, [ADR-004](../adr/ADR-004-public-home.md)).
- 외부 의존은 포트 뒤 기본값으로 둔다. 파일은 로컬 디스크, 메일은 outbox, PDF·HTML 패키지 열기는 501 이다([ADR-003](../adr/ADR-003-external-ports.md)).

## 가정

r3 §2 의 7개다. 틀리면 해당 절을 다시 본다.

1. 기획안 v3 가 제품 정본이고 시안은 화면 참고다(파이프라인 v3 끝 문장). 기획안·파이프라인·시안은 미추적 상태로 둔다.
2. 공개홈은 별도 트랙이다. 파일은 시안/ 에서 저장소 루트로 옮겨졌고 이유는 모른다. 커밋하지도 고치지도 않는다.
3. 승인자는 1인, 저장소는 하나, 문서 정본 경로는 docs/process/ 다(SDLC §2.B). 기본 브랜치는 master 다.
4. 1차 소비자는 계약 시험과 OpenAPI 다. 외부 의존은 포트 뒤에 둔다. 파일은 로컬 디스크 `var.nosync/files`(gitignore), 메일은 outbox(보내지 않음), PDF·HTML 패키지 열기는 501 이다.
5. 시험 자료는 가명이다. 날짜는 `Today`(Asia/Seoul) 한 곳에서 받고 시험이 주입한다.
6. 재입장은 그 강의의 현재 코드와 등록 이메일이면 정지·만료·정원·종료와 무관하게 된다. 기획안 P3 "코드 만료돼도 기존 등록자는 재입장"에서 파생했다.
7. 기획안 내부 모순은 이렇게 푼다. AX 과정도 DB 가 원본이다(원칙 6). 고유 과정 "삭제"는 사용 중지다(파이프라인 9). 패키지명 classfit 은 1차 동안 유지한다.

## 영향 받는 사람·시스템

- 나중의 프론트: OpenAPI 가 계약이다. 응답은 화면 단위 조립(portal·home)과 불투명 `href` 로 준다(r3 부록 F 마지막 행).
- 공개홈 트랙: 화면이 생기면 이 API 를 부른다. CORS 출처와 봇 방지 수준은 §7-1 답에 달려 있다.
- 승인자: 의존성 승인 3건(pyyaml·argon2-cffi·python-multipart)과 태스크마다의 계획 승인·병합.

## 제약

- r3 §3 원칙 ①~⑤ 를 따른다. 코드로 지키는 자리는 [spec.md](../spec.md) 2절이다.
- 착수 조건은 r3 §1 이다. pyyaml(dev)은 T0b, argon2-cffi 는 T1, python-multipart 는 T2b 의 착수 조건이다.
- 수명·만료 값은 제안값이고 설정 칸 하나로 바꾼다([Design](../2026-10-21-phase1-backend-design.md) 1절).
